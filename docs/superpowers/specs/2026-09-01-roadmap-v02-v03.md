# UI/UX 改版 + v0.2/v0.3 总实施路线

> 状态：已批准（2026-09-01）
> 背景子文档：5 份子项目 spec（`docs/superpowers/specs/2026-09-01-*-design.md`）
> 执行方式：每个子项目独立 spec → 实施计划（writing-plans）→ 实施 → E2E 全绿 → 合并 main

## 子项目与顺序

| 顺序 | 子项目 | spec | 依赖 | 交付物 |
|---|---|---|---|---|
| A | Unraid 7.3.2 部署 | `2026-09-01-unraid-deploy-design.md` | 无 | 多阶段 Dockerfile（内置 libfdk）、PUID/PGID entrypoint、compose 面向 Unraid、GHCR CI、部署文档 |
| B | 数据持久化 | `2026-09-01-persistence-design.md` | 无 | SQLite 三表（settings/session/jobs）、设置/会话/import API、localStorage 一次性迁移、任务历史分页+产物清理语义 |
| C | 模板批处理+重命名 | `2026-09-01-template-batch-design.md` | B（注册表一致性） | 模板引擎（parse/render/match）、TrackNum 特殊处理、转码模板升级、uploads/outputs 批量重命名+mutagen 写 tag、嵌入式批处理 UI+实时预览 |
| D | 网页播放/A-B 对比 | `2026-09-01-web-playback-design.md` | B（引用校验） | Range 流式端点（产物/源/书库）、章节解析、mini 试听、A/B 双面板同步 |
| E | UX 收尾 | `2026-09-01-ux-polish-design.md` | B（通知开关）；②③④独立 | 桌面通知、全局进度总览、失败诊断、待转换表多选 |

## 已知非目标（全部子项目共同边界）

- 多用户/鉴权、云端存储、实时波形、多设备同步（roadmap §4 永久边界）
- 预设管理 UI、移动端长听优化、任务撤销窗口（YAGNI）
- arm64 镜像、CA 应用模板

## 验收基线

- 每个子项目合并前：`uv run pytest` 全绿 + `./scripts/run-e2e.sh` 全量绿 + 新增单元/E2E 覆盖
- UI 改动附截图；破坏性变更（如「清空已完成」→「清理产物」）更新对应文档
- A 的最终验收含用户手动环节（Unraid 真机 D1-D7 相关项）
